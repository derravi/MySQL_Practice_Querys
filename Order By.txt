Question 6: Alphabetical Vendors
List all columns for every vendor, but ensure the output is sorted alphabetically by the vendor_name from A to Z.

Query:
select *
from vendor
order by vendor_name;

Question 7: Reverse Customer Sort
Retrieve all customers (all columns), but sort them by their customer_last_name in descending order (Z to A).

Query:
select *
from customer
order by customer_last_name desc;

Question 8: Chronological Markets
Select the market_date and market_day from the market_date_info table, ordered from the earliest date to the latest date.

Query:
select market_date, market_day
from market_date_info
order by market_date;

Question 9: Highest Price First
From the vendor_inventory table, select the product_id and original_price, sorting the results so the most expensive items appear at the very top.

Query:
select product_id, original_price
from vendor_inventory
order by original_price desc;
