21. Scalar Subquery Filtering: Select all customer_purchases where the cost_to_customer_per_qty is greater than the overall average cost of ALL purchases.
-> select customer_id,cost_to_customer_per_qty from customer_purchases
where cost_to_customer_per_qty > (select avg(cost_to_customer_per_qty) as "Average_Cost" from customer_purchases)

22. IN Clause (List): List the details of customers who live in the same zip code as Customer ID 1.
-> select * from customer where customer_zip in (select customer_zip from customer where customer_id=1);

23. NOT IN (Exclusion): Find products that have NEVER been purchased (Product ID is not in the customer_purchases product_id list).
-> select * from product
where product_id not in (select distinct(product_id) from customer_purchases)

27. Filtering by Aggregated Result: Select vendors whose total sales (sum of quantity) is greater than the maximum sales of Vendor ID 4.
-> select vendor_id, sum(quantity) as total_sum from customer_purchases
group by vendor_id
having sum(quantity) > (select max(quantity) from customer_purchases
where vendor_id = 4);

30. Category filtering without Join: Select all products from the product table where the product_category_id corresponds to 'Fresh Fruits & Vegetables' (Find the ID using a subquery on the category table).
-> select product_id,product_category_id,product_name from product
where product_category_id = (select product_category_id from product_category
where product_category_name = "Fresh Fruits & Vegetables")
