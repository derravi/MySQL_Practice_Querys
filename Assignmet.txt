Question 1: Customer Name Sort

Retrieve all customer details, sorted alphabetically first by the customer’s last name, and then by the first name if last names are the same.

Query:

SELECT *
FROM customer
ORDER BY customer_last_name, customer_first_name;

Question 2: Inventory Management

Display the top 10 records from the vendor inventory table, sorted by quantity in descending order. If quantities are the same, sort by market date in ascending order.

Query:

SELECT *
FROM vendor_inventory
ORDER BY quantity DESC, market_date
LIMIT 10;

Question 3: Detailed Transaction History

Retrieve the 15 most recent customer purchase transactions, sorted by market date (newest first) and transaction time (newest first).

Query:

SELECT *
FROM customer_purchases
ORDER BY market_date DESC, transaction_time DESC
LIMIT 15;

Question 4: Categorized Product List

Question 5: High Value Inventory

Question 8: Extreme Weather Days

Find the top 3 market dates with the highest maximum temperature. If there is a tie, sort by minimum temperature (lowest first).

Query:

SELECT market_date
FROM market_date_info
ORDER BY market_max_temp DESC, market_min_temp
LIMIT 3;

List the 5 market dates with the lowest minimum temperature. If temperatures tie, list the one with the lower maximum temperature first.
